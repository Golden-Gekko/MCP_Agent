# MCP Agent

AI-агент для кодирования, использующий LangChain, LangGraph и Model Context Protocol (MCP).

## Описание проекта

Проект представляет собой AI-агент, который:
- Использует большие языковые модели (LLM) для генерации и обработки кода
- Интегрируется с MCP-серверами для взаимодействия с внешними инструментами
- Отслеживает все шаги работы через Langfuse
- Поддерживает работу с локальными LLM через vLLM или Ollama

### Основные компоненты

- **agent/** — логика агента (графы, планировщик, узлы, финализатор)
- **app/** — приложение и интерфейс
- **core/** — базовые настройки и логирование
- **tools/** — MCP-инструменты
- **utils/** — вспомогательные утилиты (Langfuse)
- **report/** — генерация отчётов

## Требования

- Python 3.11+
- Docker и Docker Compose
- uv (менеджер пакетов)

## Установка

### 1. Установка зависимостей

```bash
uv sync
```

### 2. Настройка окружения

Скопируйте файл примера и заполните переменные окружения:

```bash
cp .env.example .env
```

## Запуск

### Вариант 1: Через Docker Compose (рекомендуется)

Запуск с vLLM:
```bash
make up WS=
```

В параметре WS указывается путь к рабочей пространству агента

Запуск с Ollama:
```bash
make up-o
```

Остановка:
```bash
make down
```

Пересборка и запуск:
```bash
make rebuild
```

### Вариант 2: Локальный запуск

```bash
uv run python main.py
```

## Порты

- **8000** — интерфейс агента
- **3000** — Langfuse UI
- **30000** — vLLM (если используется)
