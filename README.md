# MCP Coding Agent (Часть 1: Инфраструктура и базовый агент)

Локальный AI-агент для написания кода и работы с файловой системой и git

Статья на [Хабре](https://habr.com/ru/articles/1043348/)

## Предварительные требования

Перед запуском убедитесь, что у вас установлены:
- Docker и NVIDIA Container Toolkit.
- Менеджер пакетов Python [uv](https://docs.astral.sh/uv/).
- [Node.js](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm) (требуется `npx` для запуска MCP-серверов `filesystem` и `context7`).
- [Git](https://git-scm.com/install/windows) (для работы MCP-сервера `git`).

## Быстрый старт

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/Golden-Gekko/MCP_Agent.git
cd MCP_Agent
git checkout simple
```

### 2. Настройте окружение
Создайте файлы `.env` и `.langfuse.env` на основе примера и заполните его своими данными

### 3. Установите зависимости

```bash
uv sync
```

### 4. Запустите инфраструктуру

Используйте предоставленный `Makefile` для поднятия контейнеров с моделями инференса. 

> **Важно:** При первом запуске модели будут загружены из Hugging Face, это может занять время в зависимости от скорости интернета.

```bash
make up
```

Далее, с помощью мигратора импортируйте промпты в предварительно настроеный LangFuse:

```bash
cd langfuse_migrations
python main.py --import
cd ..
```

### 5. Запустите приложение

```bash
python main.py

# или

uv run main.py
```
После запуска в консоли появится ссылка на локальный веб-интерфейс Gradio.

### 6. Подготовка рабочего пространства

Агент проверяет валидность рабочей директории перед запуском инструментов. Чтобы инструменты Git и Filesystem подключились корректно:

1. Создайте пустую тестовую папку (или укажите путь к существующему пет-проекту в `AGENT__WORKSPACE`).
2. Инициализируйте в ней Git-репозиторий
3. Убедитесь, что путь к этой папке указан в вашем `.env` файле.
